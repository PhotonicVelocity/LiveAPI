This site documents the Ableton Live Object Model. The structural surface
(types, listenability, settability, signatures) comes from runtime
introspection. The behavioral surface (when does a mutation become visible,
what fires a listener, what raises) is being built up incrementally — see
the [documentation roadmap](https://github.com/PhotonicVelocity/LiveAPI/blob/reference-doc-generator/doc/reference-roadmap.md)
for the path.
