---
title: CcControlDevice
description: "Represents a CC Control device — Live's MIDI utility that maps an incoming MIDI control to a chosen target."
---

Represents a CC Control device — Live's MIDI utility that maps an incoming
MIDI control to a chosen target. The `CcControlDevice` class extends
`Device` with the custom-target selectors and lists that drive its mapping
UI.
