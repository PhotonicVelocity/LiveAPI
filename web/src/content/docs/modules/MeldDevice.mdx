title: MeldDevice
description: "Represents an instance of Meld, Live's bi-oscillator macro-driven synthesizer."
---

Represents an instance of Meld, Live's bi-oscillator macro-driven
synthesizer. The `MeldDevice` class extends `Device` with Meld-specific
state on top of the inherited parameter and preset surface.
