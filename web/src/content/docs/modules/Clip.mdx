Represents a clip in Live, either an audio or MIDI clip living in an
Arrangement track or a Session view slot. The `Clip` class drives clip
playback, looping, warp markers, MIDI note editing, and automation envelopes.


### <span class="sig"><span class="sig-name" data-path="Live.Clip.">Clip</span></span><a class="lom-badge" href="/LiveAPI/live-object-model/" title="This is a LomObject — see the LomObject page for the universal identity / lifetime model" aria-label="LomObject"></a>

This class represents a Clip in Live. It can be either an Audio Clip or a MIDI Clip, in an Arrangement or the Session, depending on the Track (Slot) it lives in.<sup class="source-marker" tabindex="0" aria-label="from Live's runtime docstring"><span class="source-marker-tooltip" role="tooltip"><span class="sm-note">From Live's runtime docstring.</span></span></sup>
