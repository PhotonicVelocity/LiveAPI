Represents a clip in Live, either an audio or MIDI clip living in an
Arrangement track or a Session view slot. The `Clip` class drives clip
playback, looping, warp markers, MIDI note editing, and automation envelopes.


### <span class="sig" data-kw="class"><span class="sig-name" data-path="Live.Clip.">Clip</span></span> <a class="lom-badge" href="/LiveAPI/modules/lomobject/" title="This is a LomObject — see the LomObject page for the universal identity / lifetime model">LomObject</a>

This class represents a Clip in Live. It can be either an Audio Clip or a MIDI Clip, in an Arrangement or the Session, depending on the Track (Slot) it lives in.
