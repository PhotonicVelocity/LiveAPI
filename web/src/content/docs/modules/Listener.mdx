Holds the bookkeeping types behind Live's listener callbacks. The
`ListenerHandle` class wraps an active subscription on an observable LOM
property; the `ListenerVector` collects multiple handles for bulk lifetime
management.


## Classes

### <span class="sig" data-kw="class"><span class="sig-name" data-path="Live.Listener.">ListenerHandle</span></span>

This class represents a Python listener when connected to a Live property.

##### name<span class="prop-type">: str</span>
