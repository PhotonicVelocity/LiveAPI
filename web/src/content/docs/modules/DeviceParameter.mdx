title: DeviceParameter
description: "Represents a single automatable parameter on a device or mixer in Live."
---

Represents a single automatable parameter on a device or mixer in Live. The
`DeviceParameter` class exposes the parameter's current value, range,
display string, automation state, and MIDI/key mapping target.


### <span class="sig"><span class="sig-name" data-path="Live.DeviceParameter.">DeviceParameter</span></span><a class="lom-badge" href="/LiveAPI/live-object-model/" title="This is a LomObject — see the LomObject page for the universal identity / lifetime model" aria-label="LomObject"></a>
