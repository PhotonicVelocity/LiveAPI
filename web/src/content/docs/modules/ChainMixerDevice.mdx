Represents the mixer attached to a single rack `Chain`. The
`ChainMixerDevice` class exposes the chain's volume, pan, mute, solo, and
per-chain sends as `DeviceParameter` objects.


### <span class="sig" data-kw="class"><span class="sig-name" data-path="Live.ChainMixerDevice.">ChainMixerDevice</span><span class="sig-base">(<a href="/LiveAPI/modules/lomobject/#lomobject">LomObject</a>)</span></span>

This class represents a Chain's Mixer Device in Live, which gives you access to the Volume, Panning, and Send properties of a Chain.
