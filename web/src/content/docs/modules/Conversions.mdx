Module-level functions that turn Live content from one form into another —
audio clips into MIDI, audio clips into a Drum Rack, drum pads into a new
MIDI track, and audio clips into Simpler-backed MIDI tracks.


## Enums

### <span class="sig" data-kw="enum"><span class="sig-name" data-path="Live.Conversions.">AudioToMidiType</span></span>

## Functions

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">audio_to_midi_clip</span></span>()

Creates a MIDI clip in a new MIDI track with the notes extracted from the given audio_clip. The `audio_to_midi_type` decides which algorithm is used in the process. Raises error when called with an inconvertible clip or invalid `audio_to_midi_type`.

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">create_drum_rack_from_audio_clip</span></span>()

Creates a new track with a drum rack with a simpler on the first pad with the specified audio clip.

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">create_midi_track_from_drum_pad</span></span>()

Creates a new Midi track containing the specified Drum Pad's device chain.

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">create_midi_track_with_simpler</span></span>()

Creates a new Midi track with a simpler including the specified audio clip.

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">is_convertible_to_midi</span></span>()

Returns whether `audio_clip` can be converted to MIDI. Raises error when called with a MIDI clip

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">move_devices_on_track_to_new_drum_rack_pad</span></span>()

Moves the entire device chain of the track according to the track index onto the C1 (note 36) drum pad of a new drum rack in a new track.If the track associated with the track index does not contain any devices nothing changes (i.e. a new track and new drum rack are not created).

### <span class="sig" data-kw="def"><span class="sig-name" data-path="Live.Conversions.">sliced_simpler_to_drum_rack</span></span>()

Converts the Simpler into a Drum Rack, assigning each slice to a drum pad. Calling it on a non-sliced simpler raises an error.
