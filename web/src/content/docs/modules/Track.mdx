Represents an audio, MIDI, return, or main track in a Live Set. The `Track`
class hosts the track's clip slots, devices, mixer, and routing — not all
properties are supported by every track type, and individual members are
marked accordingly.


### <span class="sig" data-kw="class"><span class="sig-name" data-path="Live.Track.">Track</span><span class="sig-base">(<a href="/LiveAPI/modules/track/#devicecontainer">DeviceContainer</a>)</span></span>

This class represents a track in Live. It can be either an Audio track, a MIDI Track, a Return Track or the Main track. The Main Track and at least one Audio or MIDI track will be always present. Return Tracks are optional.
