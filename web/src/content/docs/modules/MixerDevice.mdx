Represents the per-track mixer in Live. The `MixerDevice` class exposes
volume, panning, sends, cue volume, crossfader assignment, and track
activator as `DeviceParameter` objects ready for automation or remote
control.


### <span class="sig" data-kw="class"><span class="sig-name" data-path="Live.MixerDevice.">MixerDevice</span></span> <a class="lom-badge" href="/LiveAPI/modules/lomobject/" title="This is a LomObject — see the LomObject page for the universal identity / lifetime model">LomObject</a>

This class represents a Mixer Device in Live, which gives you access to the Volume and Panning properties of a Track.
